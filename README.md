## 🛠️ สิ่งที่ต้องเตรียม

### ความต้องการระบบ
- **OS**: Linux, macOS, หรือ Windows
- **Lua**: เวอร์ชัน 5.4+ (แนะนำ)
- **LuaRocks**: Package manager
- **Text Editor**: VS Code, Neovim, หรือ IntelliJ IDEA

### การติดตั้ง Lua

**Ubuntu/Debian:**
```bash
sudo apt-get update
sudo apt-get install lua5.4 lua5.4-dev luarocks
```

**macOS:**
```bash
brew install lua luarocks
```

**Windows:**
```powershell
# ดาวน์โหลดจาก https://luabinaries.sourceforge.net/
# หรือใช้ Scoop
scoop install lua
```
